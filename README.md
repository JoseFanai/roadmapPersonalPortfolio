# Personal Portfolio Website
project url : https://roadmap.sh/projects/portfolio-website

A responsive personal portfolio website built using HTML and CSS. This project showcases my frontend development skills, projects, work experience, education, and testimonials.

## 🚀 Features

* **Responsive Design:** Fully responsive layout that beautifully adapts to both desktop and mobile screens using CSS Flexbox and Grid.
* **Clean UI Layout:** Simple, structured, and easy-to-read wireframe-style interface.
* **Projects Section:** Grid-based display for showcasing personal and open-source projects.
* **Experience & Education:** Dedicated sections to highlight professional background and academic details.
* **Contact Form:** A styled contact section for user inquiries.

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox, CSS Grid, Media Queries)
* Google Fonts (Isometra)
